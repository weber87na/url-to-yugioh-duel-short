# 視覺系統與人物動作

本風格的識別點是像素人物／場地加上清晰的實體卡牌質感。先看 [全場構圖](../assets/style-reference.jpg)、[卡片樣式](../assets/card-style-reference.jpg) 與 [九格場景序列](../assets/scene-sequence-reference.jpg)。沿用構圖與材質方法；角色、卡片效果、HP、片長與勝負依當次劇情。

## 版面與層級

預設採「放大決鬥場＋緊湊資訊列」構圖，畫布 1080×1920、30 fps。主戰場約占畫面高度八成；上方保留片名、回合、對手 HP 與小型「卡牌戲仿」標示，下方僅保留玩家 HP。敘事由場內發動、效果與勝負提示交代，不設常駐 DUEL LOG 大面板或底部兩行註記。

像素場景可在 540×960 繪製後以 nearest-neighbor 放大 2 倍。卡牌、字幕、清晰 UI 及真人資料畫面在最終解析度獨立合成。下表皆為 **1080×1920 最終像素座標**；若畫於邏輯畫布，座標除以 2。這些是已驗收的配置起點，可依人物及輸出需求調整。

| 區域 | 最終像素座標參考 |
| --- | --- |
| 標題／對戰名 | y 28–117 |
| 回合與敵方 HP | y 134–231 |
| 主戰場 | x 26–1054、y 250–1790 |
| 玩家 HP | x 26–1054、y 1810–1900 |
| 原音字幕 | 場內無人臉／卡名的空隙；只在語音期間出現 |
| 戲仿標示 | 上方小標；原音字幕附講者及「歷史原音」 |

底色 `#081421`，面板 `#112b3b`，玩家青綠 `#54e1cc`，敵方紫 `#c6a0ff`，金色重點 `#edce8d`，危機珊瑚紅 `#ff7f82`。可隨主題調色，避免每個區塊都同時搶眼。

戰場用透視桌面、怪獸區與魔法陷阱槽，牌堆位於近景側邊。玩家左下大、對手右上小，雙方朝向戰場；怪獸依 owner 放在正確場區。初始與後續 HP 都讀當次工程，不把範例的「1 HP」寫死於 UI。

擴大場景時，重新繪製桌面及卡槽，分別調整角色腳底位置並等比例放大人物／卡牌；不能拉伸已合成畫面。1080 寬版可先以玩家站姿約 600 px、對手約 470 px、場上怪獸約 360 px 配置；玩家腳底約 (270,1748)、對手約 (800,980) 作為起點，再按最大動作外框調整。人物數量與怪獸位置由劇情決定。

卡牌特寫可先採約 600 px 寬，高度按原卡比例計算（約 874 px）。完整保留卡框、卡名、效果欄及右下角，與 HP 列留出間隙；旋轉後重新檢查外框。亮牌可暫壓暗背景，提示框與勝負框須避開仍需辨識的角色臉。

原音字幕只在已核對的語音時段出現，顯示原文、講者及「歷史原音」；遊戲敘事另放事件提示。場內字幕條可先放 x145–935、y1012–1114，但必須依人物頭部、手臂及卡面的位置調整，無台詞時不留下空面板。字幕與 SRT 使用同一份權威 cue 清單，避免舊工程不同字幕欄位造成漏句。

## 真卡與自創卡

依 [卡片樣式與來源規格](card-style.md) 製作。指定真卡先核對官方資料與版本；自創卡使用對應卡種的精細紋理框、寫實幻想插圖及清晰繁體文字，標為戲仿。卡背使用可查核的實卡素材，牌堆、抽牌與明顯手持背面保持一致。

原生 ImageGen 負責插圖創作／修圖，程式負責卡框、文字及合成。卡圖 resize 用 LANCZOS、旋轉用 BICUBIC 並保持比例，不先縮入像素場景再放大；特寫停留至觀眾能看清卡名與關鍵效果。

## 人物與怪獸

先用來源代表幀確認臉、髮型、服裝和持牌方向，再生成帶 Alpha 的動作圖。玩家背側、對手前側，雙方朝向戰場；臉可偏動漫像素，但應可辨識。

常用八姿勢只是方便排版：待機持牌、蓄勢／說話、出牌／發動、受擊、低血量、抽牌／勝利、特殊效果準備、特殊效果空中／結果。按角色實際事件改姿勢表，不為八格湊無用動作。怪獸有自己的待機、蓄力、攻擊、受擊、消失等姿勢。

圖集提示詞骨架：

> Transparent RGBA sprite atlas, [columns] by [rows], consistent [character] identity, costume, scale and pixel-art finish. [Player three-quarter back view facing right / opponent three-quarter front view facing left]. Full body including fingertips, held cards and shoes in every pose. Clear transparent gutters; no pose touches another. Pose order: [explicit list]. No labels, captions, border, ground, detached extra limbs, duplicates or background.

生成後檢查實際 Alpha，不把棋盤格背景當透明。站姿高度與腳底錨點固定，同一人物所有姿勢沿用同一比例；躺下或跳躍不能依各自外框高度重新拉大。以完整連通範圍註冊，伸出的手跨過虛擬網格時要保留。

使用原圖座標記錄每姿勢錨點，再依統一比例換算到舞台；裁切後原點不同的姿勢須同步更新錨點。橫向倒地或大幅伸手時，調整角色位置以保留手腳及道具，不用任意縮放單一姿勢掩蓋裁切。

動作狀態應連續：準備／抽牌 → 發動 → 受擊 → 低血量或倒地。受擊動畫結束後，低血量姿勢持續到後續事件改變狀態，不立即回健康站姿。事件的表情覆寫只作用於反應階段，不能吃掉此前的抽牌動作。HP 在 `impact_at` 更新，前後姿勢亦依同一時間軸決定。

## 浮手／裁切修正

只對外框裁切不夠：某姿勢的外框可能包含鄰格的手。使用 `scripts/sprite_tools.py` 的 `isolate_pose(sheet, bounds, seed_points)`，種子是**整張圖集座標**，位於人工確認的身體／道具不透明區。

```python
from sprite_tools import isolate_pose
pose, audit = isolate_pose(sheet_rgba, bounds=(x0, y0, x1, y1),
                           seed_points=[(body_x, body_y)])
# pose 只用於合成；保留原始 ImageGen 圖集。
```

先在全圖標記連通元件，再於範圍內只保留選定元件和一圈原始半透明邊緣。合法分離道具、特效或獨立手勢可加多個種子；不能一律「只保留最大塊」。種子落透明區、身體延伸到外框以外或兩個姿勢黏在一起時，停止自動裁切並重新註冊／生圖。

這個函式解決合成取樣問題，不會修正圖本身多手指、畸形手或缺肢。來源圖的解剖問題用 ImageGen 針對該姿勢修正。

## 光暈與合成效率

重複光圈可用局部 RGBA 圖層：取效果外框，四周擴充約四倍 Gaussian blur 半徑及線寬所需餘量，裁至畫布內；在局部座標繪製／模糊，再按原全圖座標貼回。保留原本模糊半徑、透明度、位置和時點，以代表幀對照確認光暈未截斷或位移。這項方法可減少每幀全畫布模糊的成本，不改變事件節奏。

固定字型與同尺寸素材可快取。正式輸出前仍看全場、最大卡面、抽牌至反應、受擊至低血量／倒地、原音字幕與結尾；確認提示未遮臉、角色與旋轉卡面未出界、HP 與場景之間有留邊。
